## Goal
The Next.js dashboard shell: a home page listing projects and a project page with the module board, rendered on the M1.1 entity shapes from a mock source, so the API source can replace it without page changes. "Done when": **20 mock projects render in under 2 s.**

| `/` | Project cards: name, stage, paused flag, approvals waiting, modules merged/total, spend vs cap (USD), lanes, last update (IST); readiness panel placeholder |

## Output safety (ADR-0011 §2)
- **Escaped output:** every value is rendered as a React text node or attribute; spec, summaries and logs are plain text in `<pre>`/`<p>`. Links are emitted only for `http:`/`https:` URLs; anything else is text.
- **No raw-HTML sinks or inline styles:** `pnpm lint` (`scripts/no-raw-html.mjs`) fails on `dangerouslySetInnerHTML`, `innerHTML`/`outerHTML`, `insertAdjacentHTML`, `document.write`, `eval`, `new Function`, `createContextualFragment`, `srcdoc`, `style={…}` and literal `<script` in dashboard source.
- **Strict CSP, per request** (`middleware.ts`, no matcher: it runs on **every** path, so HTML 404s and error pages near asset paths also get it — PR15-r1): a fresh 144-bit nonce per request; `default-src 'none'; script-src 'nonce-…' 'strict-dynamic'; style-src 'self' 'nonce-…'; img-src 'self' data:; font-src 'self'; connect-src 'self'; manifest-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'; frame-src 'none'; worker-src 'none'; require-trusted-types-for 'script'; trusted-types nextjs nextjs#bundler 'allow-duplicates'`. No `unsafe-*`, no hosts. Every page is rendered per request (`force-dynamic`, layout reads `headers()`), so Next.js puts this request's nonce on every script it emits.
- **Other headers on every response** (pages, 404s, static assets; `next.config.mjs`): `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `Permissions-Policy`, `Cross-Origin-Opener-Policy` and `-Resource-Policy: same-origin`, `X-DNS-Prefetch-Control: off`, `X-Permitted-Cross-Domain-Policies: none`; pages and HTML 404s also `Cache-Control` with `no-store` (hashed `/_next/static/` assets may be cached); no `X-Powered-By`; `Strict-Transport-Security` when served over TLS.

## Decision M1.3-a — browser-trusted HTTPS (ADR-0011 §6; Architect, D10)
**`tailscale cert` with TLS terminated in process; no Traefik hop, no Serve.**
- `server.mjs` serves HTTPS when `DEVOS_TLS_CERT_FILE` and `DEVOS_TLS_KEY_FILE` point at the `tailscale cert <host>.<tailnet>.ts.net` output (a browser-trusted Let's Encrypt certificate), TLS ≥ 1.2, and adds HSTS. One of the two set → start-up stops with `config-tls-incomplete`. Neither set → plain HTTP (local and CI only).
- **v1.1 (9 Nov 2026, DEVOS-84, found by KK at first launch):** with both TLS variables empty in Coolify the dashboard served plain HTTP and the browser showed ERR_SSL_PROTOCOL_ERROR. Now the dashboard reads M1.2's `DEVOS_COOKIE_SECURE` with the same rule (`1` on; `0`/unset off; anything else → `config-cookie-secure-invalid`). With `DEVOS_COOKIE_SECURE=1` (the server default) start-up stops with `config-tls-required` unless both files can be read as non-empty regular files (unset, half set, missing, empty or a directory all fail); it never falls back to plain HTTP. Files are read once at start-up, before Next.js is prepared or a port is bound. With `DEVOS_COOKIE_SECURE=0`/unset the old rule stands, and a set but unreadable pair is `config-tls-unreadable` (it used to surface as `startup-failed`). The log line carries only the code, never a path or file contents.
- **Release dependency (not done here, one module = one PR):** `deploy/compose.yaml` must pass `DEVOS_COOKIE_SECURE: ${DEVOS_COOKIE_SECURE:-1}` to the `dashboard` service as it already does for `api`; until it does, the dashboard sees the variable unset and keeps the plain-HTTP fallback on the server. Filed as an R1 follow-up.
- **Why not Traefik:** a proxy hop would replace the tailnet peer address that M1.2's whois identity check depends on (M1.2 "Deploy requirements"). **Why not Serve:** ADR-0005.
- **For Release / the server agent (recorded, not done here):** publish the dashboard port on the tailnet address only; mount the cert files read-only; renew with a timer running `tailscale cert` (certificates last 90 days) and restart on change; set M1.2's `DEVOS_COOKIE_SECURE=1` and put the dashboard's `https://` origin in `DEVOS_ALLOWED_ORIGINS`. The API gets the same in-process TLS when it is deployed.

## Layout
Works from 360 px: cards and board columns are fluid grids (`minmax(min(100%, …), 1fr)`), long unbroken text wraps (`overflow-wrap: anywhere`), no horizontal scroll at 390×844. Light and dark by `prefers-color-scheme`.

## Configuration (names only)
`HOST` (default `127.0.0.1`), `PORT` (default 3000), `DEVOS_TLS_CERT_FILE`, `DEVOS_TLS_KEY_FILE`, `DEVOS_COOKIE_SECURE` (`1` = HTTPS required, DEVOS-84). Start-up errors log only a controlled code (`config-*` or `startup-failed`).
