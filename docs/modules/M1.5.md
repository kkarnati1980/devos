## Interface (`@devos/run-engine`)
- `RunAdapter` (ADR-0009): `start(task, envelope)`, `events()` (adapter events), `cancel(runId)`, `result()` → `{ status, costUsd, costEstimated, usage, error? }`.
  - `ClaudeAgentSdkAdapter({ query, toolGate? })` — cancel = the SDK `AbortController`; resume = the SDK session id stored in the checkpoint; `allowedTools` = the envelope's tools; `toolGate` wires a per-tool policy check into the SDK `canUseTool` hook (deny on false or error). Cost = the SDK result's `total_cost_usd`.
  - `CodexExecAdapter({ bin?, args?, prices?, estimateUsd, killGraceMs?, env? })` — runs `codex exec --json --model <m> -` (prompt on stdin, never argv) in its **own process group**; cancel = SIGTERM to the group, SIGKILL after the grace (default 5 s). Only the passed `env` (plus `PATH`) reaches the child. Tokens come from `turn.completed.usage` (`input_tokens`, `cached_input_tokens`, `output_tokens`); cost = tokens × `prices[model]`. Without usage or a price the run is charged `estimateUsd` and marked `costEstimated` (decision M1.5-c).
- `RunEngine({ store, policy, adapterFor, startTimeoutMs = 30 s, idleTimeoutMs = 10 min, resultTimeoutMs = 15 s })`
  - `execute({ runId, provider, prompt, cwd, tag?, reserveUsd?, reserveTokens? }) → RunOutcome` `{ status, errorType, retryable, countsAsAttempt, costUsd, costEstimated, turns, lastSeq, cardId? }`.
  - `cancel(runId)`.
- `RunQueue({ redisUrl, name?, attempts = 3, backoff?, concurrency = 1 })`: `enqueue(input)` (job id = run id), `start(engine)`, `deadLetters()`, `retryDead(jobId)`, `close()`. `backoffDelay(attempt)` = uniform jitter in `[0, min(max, base·2^(attempt−1))]`.
- `RunStore` with `PrismaRunStore(createDb(url))` (every call in a transaction bounded by 10 s `timeout`/`maxWait` and a transaction-local `statement_timeout`) and `MemoryRunStore` (tests).

## Behaviour
1. **Paused project:** if `project.paused_at` is set, `execute` returns `paused` without a policy decision or a runtime start.
2. **Reserve first (fail-closed):** one `decide` per run with `action.type = "model.run"`, `budgeted: true`, provider, `costUsd` = `reserveUsd` (default: the run's remaining `max_cost_usd`), `tokens` = `reserveTokens` (default: the envelope's `maxTokens`, else 1,000,000) and the run's envelope from `capability_envelope`. If `decide` rejects it is a deny.
3. **Stop on a deny:** a `status` event, a checkpoint, a `run_error` (`budget_exceeded` or `policy_denied`, `counts_as_attempt = false`), a card (a pending `destructive_or_spend` `approval` on the project: `raise-budget` / `review-policy-denial`), then an `error` event. A budget stop also sets `project.paused_at` (cap pause) and ends the run `limit_hit`; a policy denial ends it `failed`. The runtime never starts.
4. **Events:** every adapter event is stored as a `run_event` with a gapless `seq` continuing from the last stored seq (the M1.1 trigger rejects a gap). The run always ends with exactly one `done` (success) or one typed `error` event.
5. **Per turn** (each `usage` event): a `run_telemetry` row (tokens, context size, tool name, tool-result bytes, `tag` when the run carries one — `standard_selection` for selection-loop tokens) and a checkpoint `{ turn, lastSeq, costUsd, tokens, state }`.
6. **Limits:** `max_turns` reached → cancel, `limit_hit` (`max-turns`); `max_seconds` or no event for `idleTimeoutMs` → cancel, `limit_hit` (`timeout`); cost over `max_cost_usd` → `limit_hit` (`budget_exceeded`), project paused, card. A limit never counts as a failed attempt.
7. **Settle:** after the runtime ends the reservation is reconciled with the actual cost and tokens (released when nothing was used), and one `cost_entry` row is written (Decimal rounded up to the micro-dollar).
8. **Crash and resume:** if the store fails mid-run (the worker is as good as dead) the engine settles the reservation and cost, then rethrows, so the queue retries. The next `execute` reads the last checkpoint, emits `status: resumed`, continues the turn count and the seq, and resumes the same SDK session (Claude). Across runtimes or escalation steps it is a handoff, never another runtime's session (ADR-0009 §5).
9. **Retries:** the queue retries only `failed` outcomes whose error is retryable (`provider_error`, `rate_limited`, `timeout`) and thrown store errors, with exponential backoff and full jitter. Every other failure is a BullMQ `UnrecoverableError`: never retried. `limit_hit`, `cancelled` and budget/policy stops complete the job (they are not queue failures).
10. **Dead letter:** a job that fails for good stays in BullMQ's failed set (`removeOnFail: false`). `deadLetters()` lists it (job id, run id, reason, attempts, time); `retryDead()` re-queues it. The dashboard page and API route for it are wiring for M2.x (follow-up issue).
11. **Attempts:** `countsAsAttempt` is false for `policy_denied`, `budget_exceeded`, `cancelled` and every `limit_hit`. The 3-attempt / Sonnet → Sonnet → Opus ladder (M3.6) reads it.

## Acceptance tests
Unit tests (`packages/run-engine/test/run-engine.test.mjs`, CI `build`) against `MemoryRunStore` and the real `PolicyEngine` (`MemoryPolicyStore`); the Codex adapter runs a fake `codex` script as a real child process. Starred items are also proven in `test-db/` (workflow `run-engine-db`: `PrismaRunStore` + `PrismaPolicyStore` on Postgres 17, `RunQueue` on Redis 7.4).

| # | Pass when |
|---|---|
| AT1* | Both adapters emit gapless numbered events ending in `done` or a typed `error` |
| AT2 | Cancel stops each runtime within 10 s and records `cancelled` (Codex: the whole process group, incl. a grandchild and a parent that ignores SIGTERM) |
| AT3* | Budget exceeded → run paused at a checkpoint, card raised, project paused, `countsAsAttempt=false`; the next run of the paused project does not start; cost over `max_cost_usd` does the same |
| AT4* | Every Claude and Codex run has a reservation and a reconciled actual; Codex without usage is a flagged estimate |
| AT5* | Telemetry rows exist per turn with token counts and tool-result bytes; selection tokens are tagged `standard_selection` |
| AT6* | A killed run resumes from its checkpoint (same session, seq continues gaplessly, turns continue) |
| AT7 | Max turns and max seconds end `limit_hit`, never an attempt |
| AT8 | A policy (envelope) denial stops before the runtime, raises a card and is not an attempt |
| AT9* | Backoff is exponential with full jitter; a non-retryable error is never retried; a retryable one is retried until it succeeds |
| AT10* | A poisoned job lands in the dead-letter view and can be retried; a tool gate can deny a tool through the SDK hook |
