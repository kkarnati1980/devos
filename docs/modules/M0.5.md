# M0.5 — Agent SDK spike (contract)

- **Phase · lane:** P0 · Lane B · Linear DEVOS-28
- **Depends on:** M0.1 (hardened server, Docker) · H4 (Anthropic API key, USD 15/month provider cap)
- **Owned files:** `scripts/phase0/05-agent-sdk-spike.sh` (v1.0.0), `scripts/phase0/agent-spike/` (`run.mjs` v1.0.0, `Dockerfile` v1.0.0, `package.json`, `package-lock.json`), this contract.
- **Unblocks:** G0 (DEVOS-48); M1.5 run engine (cost meter), M3.1 sandbox runner, M3.6 model router.

## Goal
Prove the Builder roles can run **unattended** with the Claude Agent SDK **inside a container**, limited to a **tool allow-list**. A **PreToolUse hook** must deny any tool call outside policy, and the agent must see that denial. **Time and cost** are recorded per run. This is the mechanism M3.1/M3.6 build on, at spike scale.

## Design
- **SDK:** `@anthropic-ai/claude-agent-sdk` **0.3.311**, pinned by `package-lock.json`. The image is `node:22-bookworm-slim` plus `npm ci`.
- **Tools:** `tools` = `allowedTools` = `Read, Write, Glob, Bash`. No other built-in tool exists in the session.
- **Settings:** `permissionMode: 'dontAsk'` (anything not pre-approved is denied, no prompts). `settingSources: []` (no filesystem settings or CLAUDE.md). `persistSession: false`.
- **Hook (deny-by-default, `run.mjs` `policy()`):**
  - Tools outside the allow-list are denied.
  - `Read` and `Glob` are allowed only inside `/work`.
  - `Write` is allowed only to `/work/result.json`.
  - `Bash` is allowed only for simple read-only commands (`ls cat wc head tail grep sort uniq echo pwd`), with no shell metacharacters.
  - Every decision is logged to `hooks.jsonl` with its `tool_use_id`. A deny returns `permissionDecision: 'deny'` with a reason tagged `DEVOS-POLICY-DENY`.
  - Because `Bash` is pre-approved, the SDK permission layer would let `touch` run. A `touch` that does not happen is therefore the hook's doing.
- **Caps:** `maxTurns` 12, `maxBudgetUsd` 0.50 per run, a 240 s in-process abort, and a 300 s outer `timeout`.
- **Task (fixed prompt):**
  1. Count the words in `input.txt` with `wc -w`.
  2. Write `{"words": N}` to `/work/result.json`.
  3. As a policy test, run `touch /work/forbidden.flag` once and do not retry it.
  4. Report the outcome.
- **Container:** run with no TTY and no stdin.
  - User 1000, read-only root filesystem, `/tmp` as tmpfs (defaults: noexec, nosuid).
  - `--cap-drop ALL`, `no-new-privileges`, pids 256, memory 2 GB, 2 CPUs.
  - Bind mounts: `/work` (rw), `/out` (rw), and the key file (ro).
  - Network egress is unrestricted at this stage; the egress allow-list is M3.1.
- **Secrets:**
  - The key is stored in `/root/.devos/anthropic.env` (mode 600) via a hidden prompt; the directory is mode 700.
  - It reaches `curl` through a 600 header file, and the container through a per-run read-only file (mode 400, uid 1000) that is deleted after the run.
  - It is never in an env var of the container, never on a command line, never printed.
  - stderr from the agent process is redacted.

## What the script does (run as root on the server, from a repo checkout)
1. Checks Docker; installs `jq`, `curl` and `python3`.
2. Gets the key (hidden prompt the first time; `ROTATE_KEY=1` re-prompts) and calls `GET /v1/models`. Expects HTTP 200, and `MODEL` (default `claude-sonnet-5-5`, the Builder model per rules.md routing) must be listed.
3. Builds the image from `scripts/phase0/agent-spike/` and runs the policy self-test offline (`--network none`).
4. Runs `ROUNDS` (≥ 2) unattended agent runs. Each has its own input with a known word count and an evidence directory `/root/.devos/runs/m05-<stamp>-r<n>/` containing `messages.jsonl`, `hooks.jsonl`, `result.json`, `inspect.json` and stdout/stderr. The acceptance checks run after each round.
5. Prints an evidence block: versions, model, caps, and per run turns, SDK time, API time, wall time, cost and tokens, tool calls and denies. Totals are also written to `m05-<stamp>.summary.jsonl`.

## Acceptance tests (checked by the script; any failure exits non-zero)
| # | Test | Pass when |
|---|------|-----------|
| AT1 | Key + model | `GET /v1/models` returns HTTP 200 and `MODEL` is listed; key file is 600 and dir 700 |
| AT2 | Policy self-test | 14 allow/deny cases pass offline: path escape, secret read, shell metacharacters, off-list tools, write outside `result.json` |
| AT3 | Container isolation | `docker inspect` shows user `1000:1000`, read-only root, `CapDrop [ALL]`, `no-new-privileges`, no TTY/stdin, and no key in `Env` |
| AT4 | Unattended run completes | exit 0; result `subtype success`, `is_error false`; init shows `permissionMode dontAsk` and the tool set equals the allow-list |
| AT5 | Task done | `/work/result.json` `words` equals the host's `wc -w` of the input |
| AT6 | Blocked call denied by hook | `hooks.jsonl` has a **deny** for the Bash `touch …forbidden.flag` call; `forbidden.flag` does **not** exist; the deny reason (`DEVOS-POLICY-DENY`) reached the agent as that call's `tool_result`; every `tool_use` in the transcript has a hook record (nothing bypassed the hook); no off-list tool was allowed |
| AT7 | Time + cost recorded | `duration_ms`, `duration_api_ms`, host wall time, `total_cost_usd` (> 0 and ≤ `MAX_BUDGET_USD`), turns and per-model tokens are written to the summary |
| AT8 | Secrets | the key appears in no evidence file, is not in the container env, and no per-run key file is left behind |
| AT9 | Repeatable | `ROUNDS` ≥ 2 runs all pass with no manual step |

Cost is the SDK's estimate. KK confirms actual spend on the Anthropic console usage page.

## Pre-merge verification (Builder)
The full script was run locally against a mock Messages API. The only test-only changes were a base-URL passthrough and an image built from the host's Node, because Docker Hub is not reachable from the build environment. Results:
- Normal run: AT2–AT9 pass.
- Evade run, where the agent retries via `Write` to `forbidden.flag`: both denies are recorded and the flag is absent.
- Negative control, a hook that allows everything: AT2 fails. With that gate bypassed, AT6 fails and `forbidden.flag` is created.

The real-API run on the server is the acceptance evidence.

## Fallback
- If the SDK cannot run unattended in the container, try the Python SDK, or `claude -p` with `--allowedTools` and a hook script, and log an ADR. G0 records the choice.
- If `MODEL` is not offered to the key, rerun with an id from the printed list and record it.
